# Images Folder

اس folder میں future میں local logo، social sharing image یا publication photographs رکھی جا سکتی ہیں۔ موجودہ prototype میں brand mark اور decorative imagery managed project storage سے load ہوتی ہے۔ cPanel پر مکمل self-hosting مطلوب ہو تو assets کو یہاں رکھ کر `index.html` کے image URLs کو مقامی paths، مثلاً `images/logo.png`، سے بدل دیں۔
