# Private Credentials

یہ folder صرف مثال کے طور پر repository میں ہے۔ Production میں اسے domain کے public document root سے باہر منتقل کریں، مثلاً `/home/noorgeec/.cred/`۔

یہاں کبھی حقیقی password، API key، SSH key یا `.env` file commit یا upload نہ کریں۔ `admin.php` credential file کا expected path `../.cred/saltanat-admin.php` ہے۔
