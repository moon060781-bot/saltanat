# Delivery Phases — سلطنت نیوز کراچی

| مرحلہ | نتیجہ | موجودہ حالت |
|---|---|---|
| 1. بنیاد | static folders، responsive homepage اور PDF viewer | مکمل |
| 2. آرکائیو | `issues.json` اور dropdown selection | مکمل |
| 3. ادارتی workflow | password-protected `admin.php` starter | مکمل |
| 4. محفوظ deployment | `deploy.php` starter، branch rules اور audit design | ابتدائی structure مکمل |
| 5. cPanel rollout | files upload، credential folder placement اور live PDF test | hosting پر کرنا باقی |
| 6. مستقبل کی بہتری | live Git controls، richer archive search یا news database | اختیاری |

ہر phase کے بعد website کی بنیادی reading experience کو برقرار رکھنا ضروری ہے: تازہ PDF پہلے نظر آئے، archive کام کرے، اور credentials محفوظ رہیں۔
